Diffusion Models for Inverse Problems#

Once a generative model has been trained, it can be used as a prior for reconstruction. The central idea is probabilistic: instead of searching for an image that only fits the measured datum, we search for an image that is both data-consistent and plausible under the learned image distribution.

This notebook focuses on diffusion models as priors for inverse problems. We start from the Bayesian viewpoint, explain why diffusion models are particularly attractive in this setting, and then discuss three representative methods: DPS, DDRM, and DiffPIR. The emphasis is on the logic of the algorithms and on explicit code. The implementations below are intentionally compact and pedagogical: they are meant to expose the main update ideas, not to reproduce the full engineering details of the original papers.

Bayesian Viewpoint and Diffusion Priors#

Let the measurement model be

\[ \boldsymbol{y}^\delta = K\boldsymbol{x}^\dagger + \boldsymbol{e}, \]

where \(K\) is a known forward operator and \(\boldsymbol{e}\) is the measurement noise. If the noise is Gaussian with variance \(\sigma_y^2\), then the likelihood is

\[ p(\boldsymbol{y}^\delta \mid \boldsymbol{x}) \propto \exp\!\left(-\frac{1}{2\sigma_y^2}\|K\boldsymbol{x} - \boldsymbol{y}^\delta\|_2^2\right). \]

If we also have a prior distribution \(p(\boldsymbol{x})\) for realistic images, the posterior is

\[ p(\boldsymbol{x} \mid \boldsymbol{y}^\delta) \propto p(\boldsymbol{y}^\delta \mid \boldsymbol{x}) \, p(\boldsymbol{x}). \]

This formula says that reconstruction should combine two pieces of information: the likelihood, which measures agreement with the data, and the prior, which measures plausibility of the image.

Latent-variable models such as VAEs and GANs already provide a learned prior, but they constrain the solution to the range of a low-dimensional generator. Diffusion models are richer. Instead of restricting the image to lie on a fixed latent manifold, they learn how to denoise realistic images across many noise levels. This gives access to two closely related objects: a noise predictor \(\boldsymbol{\varepsilon}_\Theta(\boldsymbol{x}_t,t)\) and the corresponding clean-image estimate

\[ \widehat{\boldsymbol{x}}_0(\boldsymbol{x}_t,t) = \frac{\boldsymbol{x}_t - \sqrt{1-\bar{\alpha}_t} \, \boldsymbol{\varepsilon}_\Theta(\boldsymbol{x}_t,t)}{\sqrt{\bar{\alpha}_t}}. \]

In posterior-sampling methods, this estimate is repeatedly combined with the measurement model. The result is a family of algorithms that alternate, in different ways, between a diffusion prior step and a data-consistency step.

Note

The code cells below assume that the diffusion model from the previous notebook has already been trained and saved in ../weights/DDPMDenoiser.pth.

import glob
import math
import sys
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import torch
from PIL import Image
from torch import nn
from torch.utils.data import DataLoader, Dataset
from torchvision import transforms

sys.path.append('..')
from IPPy import operators, utilities

book_root = Path('..').resolve()
weights_dir = book_root / 'weights'
weights_path = weights_dir / 'DDPMDenoiser.pth'


class MayoDataset(Dataset):
    def __init__(self, data_path, data_shape=64):
        super().__init__()
        self.fname_list = sorted(glob.glob(f'{data_path}/*/*.png'))
        self.transform = transforms.Compose([
            transforms.ToTensor(),
            transforms.Resize((data_shape, data_shape)),
        ])

    def __len__(self):
        return len(self.fname_list)

    def __getitem__(self, idx):
        x = Image.open(self.fname_list[idx]).convert('L')
        return self.transform(x)


def make_beta_schedule(num_steps, beta_start=1e-4, beta_end=2e-2):
    return torch.linspace(beta_start, beta_end, num_steps)


def extract(coefficients, t, x_shape):
    out = coefficients.to(t.device)[t]
    return out.view(t.shape[0], *([1] * (len(x_shape) - 1)))


def sinusoidal_time_embedding(t, dim):
    half_dim = dim // 2
    exponent = torch.arange(half_dim, device=t.device, dtype=torch.float32) / half_dim
    freqs = torch.exp(-math.log(10000.0) * exponent)
    angles = t.float().unsqueeze(1) * freqs.unsqueeze(0)
    emb = torch.cat([torch.sin(angles), torch.cos(angles)], dim=1)
    if dim % 2 == 1:
        emb = torch.cat([emb, torch.zeros_like(emb[:, :1])], dim=1)
    return emb


class TimeConvBlock(nn.Module):
    def __init__(self, in_ch, out_ch, time_dim):
        super().__init__()
        self.conv1 = nn.Conv2d(in_ch, out_ch, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(out_ch, out_ch, kernel_size=3, padding=1)
        self.time_proj = nn.Linear(time_dim, out_ch)
        self.act = nn.ReLU()

    def forward(self, x, t_emb):
        h = self.act(self.conv1(x))
        h = h + self.time_proj(t_emb)[:, :, None, None]
        h = self.act(self.conv2(h))
        return h


class TinyDiffusionUNet(nn.Module):
    def __init__(self, in_ch=1, base_ch=32, time_dim=128):
        super().__init__()
        self.time_dim = time_dim
        self.time_mlp = nn.Sequential(
            nn.Linear(time_dim, time_dim),
            nn.ReLU(),
            nn.Linear(time_dim, time_dim),
        )
        self.enc1 = TimeConvBlock(in_ch, base_ch, time_dim)
        self.pool1 = nn.MaxPool2d(2)
        self.enc2 = TimeConvBlock(base_ch, 2 * base_ch, time_dim)
        self.pool2 = nn.MaxPool2d(2)
        self.bottleneck = TimeConvBlock(2 * base_ch, 4 * base_ch, time_dim)
        self.up2 = nn.ConvTranspose2d(4 * base_ch, 2 * base_ch, kernel_size=2, stride=2)
        self.dec2 = TimeConvBlock(4 * base_ch, 2 * base_ch, time_dim)
        self.up1 = nn.ConvTranspose2d(2 * base_ch, base_ch, kernel_size=2, stride=2)
        self.dec1 = TimeConvBlock(2 * base_ch, base_ch, time_dim)
        self.out_conv = nn.Conv2d(base_ch, in_ch, kernel_size=1)

    def forward(self, x, t):
        t_emb = sinusoidal_time_embedding(t, self.time_dim)
        t_emb = self.time_mlp(t_emb)
        s1 = self.enc1(x, t_emb)
        s2 = self.enc2(self.pool1(s1), t_emb)
        h = self.bottleneck(self.pool2(s2), t_emb)
        h = self.up2(h)
        h = torch.cat([h, s2], dim=1)
        h = self.dec2(h, t_emb)
        h = self.up1(h)
        h = torch.cat([h, s1], dim=1)
        h = self.dec1(h, t_emb)
        return self.out_conv(h)


def predict_x0_from_eps(x_t, eps_pred, t, alpha_bars):
    return (x_t - extract((1 - alpha_bars).sqrt(), t, x_t.shape) * eps_pred) / extract(alpha_bars.sqrt(), t, x_t.shape)


def deterministic_ddim_update(x_t, x0_hat, eps_pred, t_next, alpha_bars):
    if t_next < 0:
        return x0_hat
    alpha_bar_next = alpha_bars[t_next].to(x_t.device)
    return torch.sqrt(alpha_bar_next) * x0_hat + torch.sqrt(1 - alpha_bar_next) * eps_pred


device = utilities.get_device()
num_diffusion_steps = 200
betas = make_beta_schedule(num_diffusion_steps)
alphas = 1.0 - betas
alpha_bars = torch.cumprod(alphas, dim=0)

test_dataset = MayoDataset(data_path=str(book_root / 'Mayo' / 'test'), data_shape=64)
model = TinyDiffusionUNet(in_ch=1, base_ch=32, time_dim=128)
model.load_state_dict(torch.load(weights_path, map_location='cpu', weights_only=True))
model = model.to(device)
model.eval()

K = operators.Blurring(
    img_shape=(64, 64),
    kernel_type='motion',
    kernel_size=9,
    motion_angle=20,
)

print('Device:', device)
print('Loaded diffusion weights from:', weights_path)

with torch.no_grad():
    x_true = test_dataset[0].unsqueeze(0).to(device)
    y_delta = K(x_true)
    y_delta = y_delta + utilities.gaussian_noise(y_delta, noise_level=0.01)

plt.figure(figsize=(8, 3))
plt.subplot(1, 2, 1)
plt.imshow(x_true.cpu().squeeze(), cmap='gray')
plt.title('Ground truth')
plt.axis('off')

plt.subplot(1, 2, 2)
plt.imshow(y_delta.cpu().squeeze(), cmap='gray')
plt.title('Blurred and noisy datum')
plt.axis('off')

plt.tight_layout()
plt.show()

DPS, DDRM, and DiffPIR#

The three methods discussed below all use the same trained diffusion prior, but they combine it with the measurement model in different ways.

  • DPS uses a likelihood gradient during the reverse diffusion process.

  • DDRM exploits the structure of a linear forward operator more explicitly, often in a transformed domain where the operator becomes diagonal.

  • DiffPIR follows a plug-and-play philosophy and alternates between a denoising step and a data-consistency step.

The code that follows is deliberately compact and pedagogical. It captures the main update logic of each method, but it should not be confused with a full research-grade implementation.

DPS: Diffusion Posterior Sampling#

The idea behind Diffusion Posterior Sampling (DPS) is conceptually simple. The diffusion model provides a prior step, while the measurement model provides a gradient of the log-likelihood. For Gaussian noise, the likelihood term is proportional to

\[ -\frac{1}{2\sigma_y^2}\|K\boldsymbol{x} - \boldsymbol{y}^\delta\|_2^2. \]

DPS augments the reverse diffusion dynamics with a correction that pushes the sample toward better agreement with the measurements. This is attractive because it does not require retraining the diffusion model for each inverse problem.

def dps_reconstruct(model, y_delta, K, alpha_bars, sigma_y=0.01, sample_steps=40, guidance_scale=0.15):
    schedule = torch.linspace(num_diffusion_steps - 1, 0, sample_steps, dtype=torch.long, device=device)
    x = torch.randn_like(y_delta)

    for i in range(len(schedule) - 1):
        t_current = int(schedule[i].item())
        t_next = int(schedule[i + 1].item())
        t = torch.full((x.shape[0],), t_current, device=device, dtype=torch.long)

        x = x.detach().requires_grad_(True)
        eps_pred = model(x, t)
        x0_hat = predict_x0_from_eps(x, eps_pred, t, alpha_bars).clamp(0.0, 1.0)
        data_loss = torch.mean((K(x0_hat) - y_delta) ** 2) / (2 * sigma_y ** 2)
        grad = torch.autograd.grad(data_loss, x)[0]

        with torch.no_grad():
            x_next = deterministic_ddim_update(x, x0_hat, eps_pred, t_next, alpha_bars)
            x = (x_next - guidance_scale * grad).clamp(0.0, 1.0)

    with torch.no_grad():
        t0 = torch.zeros((x.shape[0],), device=device, dtype=torch.long)
        eps_pred = model(x, t0)
        return predict_x0_from_eps(x, eps_pred, t0, alpha_bars).clamp(0.0, 1.0)


x_dps = dps_reconstruct(model, y_delta, K, alpha_bars, sigma_y=0.01, sample_steps=40, guidance_scale=0.15)

DDRM: Denoising Diffusion Restoration Models#

DDRM is designed for linear inverse problems and exploits the structure of the forward operator more directly. At a high level, the method moves to a representation in which the operator is diagonalized, combines the diffusion prior with the noisy measurements in that transformed domain, and then returns to image space.

This is especially natural for linear problems such as deblurring, super-resolution, and inpainting. For convolutional blurs, the Fourier domain plays the role of the diagonalizing basis. The exact DDRM derivation is more subtle than the few lines below, but the following cell shows the central idea: combine a diffusion prediction with a measurement-consistency correction in a domain where the blur acts multiplicatively.

def kernel_to_otf(kernel, shape):
    psf = torch.zeros(shape, device=kernel.device)
    k = kernel.squeeze(0).squeeze(0)
    kh, kw = k.shape
    psf[:kh, :kw] = k
    psf = torch.roll(psf, shifts=(-kh // 2, -kw // 2), dims=(0, 1))
    return torch.fft.fft2(psf)


def ddrm_fourier_consistency(x0_hat, y_delta, H, lam=5e-3):
    X0 = torch.fft.fft2(x0_hat.squeeze(1))
    Y = torch.fft.fft2(y_delta.squeeze(1))
    H_batch = H.unsqueeze(0)
    X = (torch.conj(H_batch) * Y + lam * X0) / (torch.abs(H_batch) ** 2 + lam)
    x = torch.fft.ifft2(X).real.unsqueeze(1)
    return x.clamp(0.0, 1.0)


def ddrm_style_reconstruct(model, y_delta, K, alpha_bars, sample_steps=40, lam=5e-3):
    schedule = torch.linspace(num_diffusion_steps - 1, 0, sample_steps, dtype=torch.long, device=device)
    x = torch.randn_like(y_delta)
    H = kernel_to_otf(K.kernel.to(device), y_delta.shape[-2:])

    for i in range(len(schedule) - 1):
        t_current = int(schedule[i].item())
        t_next = int(schedule[i + 1].item())
        t = torch.full((x.shape[0],), t_current, device=device, dtype=torch.long)

        with torch.no_grad():
            eps_pred = model(x, t)
            x0_hat = predict_x0_from_eps(x, eps_pred, t, alpha_bars).clamp(0.0, 1.0)
            x0_hat = ddrm_fourier_consistency(x0_hat, y_delta, H, lam=lam)
            x = deterministic_ddim_update(x, x0_hat, eps_pred, t_next, alpha_bars).clamp(0.0, 1.0)

    return x.clamp(0.0, 1.0)


x_ddrm = ddrm_style_reconstruct(model, y_delta, K, alpha_bars, sample_steps=40, lam=5e-3)

DiffPIR: Diffusion Plug-and-Play Image Restoration#

DiffPIR follows a plug-and-play philosophy. Instead of deriving one specific posterior sampler, it alternates between two operations: a diffusion-model denoising step, which pushes the iterate toward the learned image prior, and a data-consistency step, which pushes it back toward agreement with the measurements. This is conceptually close to classical plug-and-play and proximal algorithms, except that the denoiser is now replaced by a diffusion prior.

def diffpir_reconstruct(model, y_delta, K, alpha_bars, sample_steps=40, tau=0.6):
    schedule = torch.linspace(num_diffusion_steps - 1, 0, sample_steps, dtype=torch.long, device=device)
    x = y_delta.clone()

    for i in range(len(schedule) - 1):
        t_current = int(schedule[i].item())
        t_next = int(schedule[i + 1].item())
        t = torch.full((x.shape[0],), t_current, device=device, dtype=torch.long)

        with torch.no_grad():
            eps_pred = model(x, t)
            x0_hat = predict_x0_from_eps(x, eps_pred, t, alpha_bars).clamp(0.0, 1.0)
            x_prior = deterministic_ddim_update(x, x0_hat, eps_pred, t_next, alpha_bars)
            residual = K(x_prior) - y_delta
            x = (x_prior - tau * K.T(residual)).clamp(0.0, 1.0)

    return x.clamp(0.0, 1.0)


x_diffpir = diffpir_reconstruct(model, y_delta, K, alpha_bars, sample_steps=40, tau=0.6)

Comparing the Reconstructions#

The cell below compares the reconstructions obtained with the three methods on the same blurred measurement. The quantitative numbers are only indicative, because the implementations here are deliberately simplified for teaching. The important point is to see that one and the same diffusion prior can be combined with the measurement model in multiple algorithmic ways.

def mse(x, y):
    return torch.mean((x - y) ** 2).item()


def psnr(x, y):
    mse_val = mse(x, y)
    return float('inf') if mse_val == 0 else -10 * math.log10(mse_val)


results = {
    'Observation': y_delta,
    'DPS': x_dps,
    'DDRM-style': x_ddrm,
    'DiffPIR-style': x_diffpir,
}

fig, axes = plt.subplots(1, 5, figsize=(15, 3))
axes[0].imshow(x_true.cpu().squeeze(), cmap='gray')
axes[0].set_title('Ground truth')
axes[0].axis('off')

for ax, (name, image) in zip(axes[1:], results.items()):
    ax.imshow(image.cpu().squeeze(), cmap='gray')
    if name == 'Observation':
        ax.set_title(name)
    else:
        ax.set_title(f'{name}\nPSNR: {psnr(image, x_true):.2f} dB')
    ax.axis('off')

plt.tight_layout()
plt.show()

for name, image in results.items():
    print(f'{name:>14} | MSE: {mse(image, x_true):.6f} | PSNR: {psnr(image, x_true):.3f} dB')

Limitations and Points of Attention#

Diffusion-based reconstruction methods are powerful, but they require careful interpretation.

  • They are computationally expensive, because each reconstruction requires many neural-network evaluations.

  • They are sensitive to the forward model. If the operator \(K\) used at test time is mismatched, the method may deteriorate badly.

  • They can produce visually convincing images that are not fully data-consistent if the likelihood term is too weak or badly tuned.

  • Hyperparameters such as the guidance strength, the noise schedule, and the number of sampling steps strongly affect the result.

  • A posterior sampler should, in principle, represent uncertainty. In practice, many simplified implementations collapse toward a single preferred solution.

It is also worth noting that the ecosystem is broader than the three methods discussed here. Related approaches include DDNM for noiseless linear inverse problems and many other variants that combine diffusion priors with optimization, proximal methods, or plug-and-play schemes.

Warning

A diffusion-based reconstruction can look extremely convincing even when it is not the correct posterior sample, or even when it is not fully consistent with the measured data. This is why quantitative evaluation and careful inspection of data consistency remain essential.
